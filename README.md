# ScreenSprout

Parental control platform for managing children's screen time, web filtering, and device usage.

## Repository Structure

```
ScreenSprout/
├── apps/
│   ├── api/          # Node.js REST API server
│   ├── web/          # Web dashboard (parent-facing)
│   ├── desktop/      # Desktop application
│   ├── ios/          # iOS application
│   └── website/      # Marketing website
├── docs/             # Product & architecture documentation
└── README.md
```
